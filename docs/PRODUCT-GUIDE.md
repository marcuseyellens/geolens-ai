# GeoLens AI 产品使用手册

> 把「AI 回答里到底提了谁」做成可核验的证据，而不是一个主观分数。

本手册覆盖 GeoLens AI 的全部正式入口：网页版、浏览器插件、iOS App 与 Android App。所有入口共用同一套账户与套餐，结果口径一致。

**技术就绪 ≠ 被推荐。** 我们只报告公开页面上可核验的技术条件与真实模型回答，不承诺收录、推荐、排名或转化。

## 1. 快速开始

| 你的目标 | 从哪开始 |
|---|---|
| 只想知道一个网址在 AI 眼里是什么状态 | 网页版「免费站点检查」，免注册 |
| 边浏览边看 AI 回答页提到了谁 | 浏览器插件「本页提及扫描」 |
| 持续跟踪品牌、做诊断与修复 | 注册账户 → 控制台 → 添加品牌 |
| 让 AI Agent 只读查询指标 | 控制台 → MCP 接入 → 生成 Agent token |

**三步看懂结果**：先看「有效样本 n_valid」确认数据够不够 → 再看逐模型的提及/推荐/链接三态 → 最后按「下一步」清单修复。任何一个比例都要连同样本量一起读。

## 2. 网页版

官网：`/`，控制台：`/app`。

### 2.1 免注册站点检查

1. 打开官网首页或 `/check`，输入网址。
2. 得到就绪度（0–100）、技术条件清单与一条首要修复建议。
3. 可生成免登录只读分享链接（`/r/:token`），把证据发给同事而无需开账户。

这里**没有综合分**；就绪度只描述可观测的技术条件，不是模型推荐概率。

### 2.2 控制台（登录后）

| 模块 | 路径 | 做什么 |
|---|---|---|
| 概览 | `/app` | 账户级指标与最近动态 |
| 品牌 | `/app/brands` | 添加品牌，进入品牌详情 |
| 品牌详情 | `/app/brands/:id` | 逐模型三态指标、运行记录、原始答案 |
| 诊断报告 | `/app/brands/:id/diagnostic` | 多维度诊断与证据导出（Growth 及以上） |
| 站点检查 | `/app/audit` | 批量网址检查（Starter 及以上） |
| 增长看板 | `/app/growth` | 趋势与对比 |
| 发布验收 | `/app/acceptance` | 上线前技术条件验收 |
| 竞品观察 | `/app/competitor` | 竞品占位信号与逐页引用路径（Scale） |
| 监控发布 | `/app/monitor` | 变更监控与告警 |
| 运行治理 | `/app/operations` | 采集健康、四数隔离、批次状态 |
| MCP 接入 | `/app/mcp` | 只读 Agent token 与 `tools/list` 说明 |
| 套餐账单 | `/app/billing` | 订阅、订单、发票 |
| 设置 | `/app/settings` | 账户、语言、通知 |

### 2.3 界面语言

首次访问且未手动选择时，按 IP 自动识别语言（中国→简体中文，港台→繁体，日/韩/西/法/德对应各自语言，其他→英文），结果缓存 24 小时。右上角下拉可手动切换：

简体中文 · English · 繁體中文 · 日本語 · 한국어 · Español · Français · Deutsch

**手动选择永远优先**于自动识别。非中文语种的长尾后台文案自动回退英文，不会出现中文残留。

## 3. 浏览器插件

支持 Chrome / Edge / Firefox（Manifest V3 + Gecko 兼容字段）。独立仓库管理，与网页版共用账户和套餐。

### 3.1 安装

1. 从 GitHub Release 下载 `geolens-lens-*.zip` 并解压。
2. Chrome / Edge：打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压目录。
3. Firefox：打开 `about:debugging` →「此 Firefox」→「临时载入附加组件」→ 选择 `manifest.json`。
4. 点击工具栏图标（可选：右键菜单「用 GeoLens 检查此网址」）。

### 3.2 三个页签

- **网址检查**：输入网址 → 得到页面体检结果与下一步建议。
- **本页提到了谁**：在 ChatGPT / Perplexity / Gemini / Claude / Bing 等页面，绿色标记你的品牌、橙色标记竞品，右下角浮层显示次数。只标记文本，不改写回答。
- **解锁更多**：列出 5 项加强能力及各自所需套餐，未订阅时全部锁定。

### 3.3 加强功能门控

能力按 `免费版 < Starter < Growth < Scale` 逐级解锁：

| 能力 | 最低套餐 |
|---|---|
| 批量网址检查 | Starter |
| 本地历史记录 | Starter |
| 完整诊断报告 | Growth |
| 原始证据导出 | Growth |
| 竞品对比面板 | Scale |

### 3.4 订阅与支付方式

插件内「订阅与方案」页展示 4 档套餐：

| 套餐 | 价格 | 主要权益 |
|---|---|---|
| 免费版 | $0 | 每天 5 次速查、当前页品牌扫描、基础修复建议 |
| Starter | $49/月 | 1500 次/月、批量检查、本地历史、1 个项目 |
| Growth | $199/月 | 9000 次/月、完整诊断、证据导出、MCP/API/告警、2 个项目 |
| Scale | $410/月 | 21000 次/月、竞品面板、自定义导出、5 个项目 |

支付方式：Airwallex（银行卡 / Apple Pay / Google Pay）、PayPal、沙盒演示。真实支付跳转到主站安全收银台完成，插件不接触银行卡信息。支付后可在订阅页用主站登录凭证同步状态（凭证仅本次使用，不写入插件存储）；沙盒演示仅用于体验流程，不产生真实扣款。

### 3.5 插件语言

与网页版一致的 8 种语言，首次启动按 IP 自动识别（24 小时缓存），设置页可手动指定。

## 4. iOS 与 Android App

两个 App 采用**原生风格移动 UI**（非网页版套壳）：底部 Tab（首页 / 速查 / 品牌 / 我的）、页面栈 push/pop 跳转、浅色工具风卡片设计，适配刘海屏安全区。功能覆盖免注册速查、品牌诊断摘要、修复清单、套餐说明与 MCP 接入指引，数据来自主站 API（可在「我的」里改服务地址，或开启演示数据离线预览）。

### 4.1 安装

- **iOS**：Release 中的模拟器构建 `GeoLensAI-simulator.app` 仅供开发验证；真机安装需要 Apple Developer 签名，请用源码自行 Archive 签名后分发。
- **Android**：下载 `geolens-ai-*.apk`，在 Android 8.0+ 设备「设置 → 安全 → 允许未知来源」后安装。

### 4.2 与网页版的差异

- API 地址默认指向生产服务，可在首次启动页配置自建服务地址。
- 登录状态、套餐、语言在应用内持久保存；切换语言会重新加载界面。
- 浏览器插件的「本页提及高亮」依赖网页 DOM，App 内不提供。
- App 是移动原生交互，不是网页版逐页搬运；深度报表、运行治理、语言切换等请在网页版使用。

## 5. 套餐与支付

### 5.1 套餐对照

见 [3.4](#34-订阅与支付方式)。免费版无需支付即可使用；加强能力需要对应套餐。

### 5.2 支付流程

1. 官网 `/pricing` 或插件订阅页选择套餐与支付方式。
2. 官网 `/subscribe` 进入主站收银台（需登录）。
3. Airwallex / PayPal 托管收银台完成支付，回调强制验签、订单幂等激活。
4. 插件端用主站凭证同步已支付订单的套餐等级。

凭证缺失时主站自动降级为演示网关，便于本地体验；兑换码走「兑换 + 人工交付」，不会自动升级套餐。

## 6. 核心概念与口径

- **三态指标**：品牌提及 / 推荐 / 链接分别统计，不合并为单一分数。
- **有效样本 `n_valid`**：每个比例的分母，过小时不要下结论。
- **四数隔离**：`planned / usable / failed / suspect` 互不折算；可疑批次只触发采集健康告警。
- **跨语言观察**：不同语言问题集分别生成、分别计费；检索语言未判定与 `locale_mismatch` 的运行不进默认分母。
- **独立参考区**：DR / DA 等传统 SEO 指标为用户自述、未经核验，与观测结果分表。
- **证据标记模板**：`[事实] / [观察] / [推导]`，排除项清单与评审否决项随报告保留。
- **历史口径不重算**：`1.0.0 / 1.1 / 1.2` 三口径并存渲染，老报告永不按新口径改写。

## 7. 常见问题

**Q：为什么没有综合分？**
A：不同模型的采样与措辞不可直接合成一个可靠数字。我们给逐模型、逐意图的可核验比例与证据。

**Q：就绪度 90 为什么还是没被推荐？**
A：技术就绪是必要条件而非充分条件。报告只说明页面可被读取、引用路径清晰，不承诺模型行为。

**Q：沙盒支付会扣款吗？**
A：不会。沙盒只在本地激活演示状态，用于体验门控流程。

**Q：网页版和 App 的套餐通用吗？**
A：通用，同一账户同一套餐。插件的沙盒演示状态仅在本地有效。

**Q：IP 自动语言识别会上传我的浏览数据吗？**
A：不会。只请求公共 IP 地理服务读取国家码用于选语言，不上传网址、品牌或订阅信息。

## 8. 隐私与数据

- 采集对象为公开页面与真实模型回答，逐条保留原始答案与引用证据。
- 插件的页面扫描完全在本地 DOM 完成，不上传页面内容。
- 最小化统计仅衡量「访问 → 检查 → 结果」漏斗，不采集个人信息、不使用广告追踪。
- 详见官网「隐私政策」「服务条款」页面。
